Installation Commands

Laravel 13 released 17 March 2026, latest 13.33.0. Laravel 11 reached EOL in March 2026 and Laravel 12’s bug-fix window closed in August 2026 — Laravel 13 is the only supported choice for a new build. Requires PHP 8.3–8.5. 

# 1. Verify PHP — must be 8.3 or newer
php -v

# 2. Create the project, pinned to Laravel 13
composer create-project laravel/laravel kundali "13.*"
cd kundali

# 3. Livewire 3 + Breeze auth
composer require livewire/livewire
composer require laravel/breeze --dev
php artisan breeze:install livewire

# 4. Frontend build + database
npm install && npm run build
php artisan migrate

# 5. Confirm version
php artisan --version
# Push to Git
git init && git add . && git commit -m "Initial Laravel 13 setup for Kundali app"
git branch -M main
git remote add origin <your-repo-url>
git push -u origin main

Project name: kundali. Laravel’s default .gitignore already excludes .env, vendor/ and node_modules/ — leave those uncommitted.
